```
Somewhere in that process I fell for logo and brand design — because
that's the first thing anyone sees of a business, and usually the thing
that decides whether they stay. So now I do all three: the mark, the
interface, and the code underneath. It turns out that's where most
projects break anyway — in the gaps between them.
```

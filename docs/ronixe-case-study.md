### 03 — The Problem
Ronixe is a software development company in Bamenda, Cameroon — web, mobile, e-commerce, UI/UX, API integration, ongoing support. Their own positioning is "we build applications from conception to launch." The mark needed to say technical and forward-moving without leaning on the two clichés every dev agency reaches for: a literal `</>` code bracket, or a generic rocket.

### 04 — Before (annotated)
*No prior identity existed — this was greenfield, not a redesign.* Skip the annotated-before block; state this directly.

### 05 — What I Did
Designed the full identity system: wordmark, standalone icon (usable alone as a favicon/app icon), and a combined lockup — each built for both light and dark surfaces, since the product itself ships dark-themed.

### 06 — Research & Constraints
The icon had to hold up at favicon size and as a full lockup on a marketing site, and needed to work on Ronixe's actual dark UI (`#0a0705` theme color) as well as light contexts like documents and stationery.

### 07 — Key Decisions (expandable rows: Chose → Rejected → Why)

**Chose:** A diagonal upward arrow set inside an open rounded-square frame, with the "R" built from the negative space where the arrow crosses the frame's edge.
**Rejected:** A literal code-bracket (`</>`) mark.
**Why:** Every second dev-agency logo reaches for a bracket. An upward arrow reads as momentum and launch — which is Ronixe's own stated positioning — and doubles as the letterform instead of sitting beside it. Same design position carried through Diwa, Monilog, Qiroke, and Yisi: meaning built into the letter, not added next to it.

**Chose:** Full light/dark variant set for wordmark, icon, and lockup independently.
**Rejected:** A single-color mark with opacity shifts for dark mode.
**Why:** The live product runs a dark theme by default. A mark that was only "adapted" for dark mode rather than purpose-built for it would have looked like an afterthought on the actual site.

### 08 — The System
- **Wordmark:** clean geometric sans, paired with the icon
- **Icon:** standalone R-mark, works down to favicon size
- **Lockup:** icon + wordmark combined, light and dark
- Each asset shipped as light and dark variants — six files total covering every surface the brand would meet

### 09 — After
Live in production at [ronixe.com](https://ronixe.com) — the mark appears in the site header, favicon, and social meta images, running on the dark theme it was built for.

### 11 — Outcomes
Unlike brand work that ends at a guidelines PDF, this one is verifiable: the mark is live, in production, on a real client's real site — not a mockup. That's the proof point for this page.

### 12 — What I'd Do Differently
No formal guidelines document shipped alongside the assets — just the file set (fullmark, icon, lockup, light/dark). It works because the system is simple enough to hold together on its own, but Diwa and Qiroke both got a documented clear-space and misuse spec, and a live production brand arguably needed that discipline too.
